`.f3d`（Fusion 360）ファイルはバイナリファイルのため、**同じファイルを2人が同時に編集するとコンフリクトになり、自動マージできません。**

- **同じファイルを同時に編集しない**（作業前に声をかけ合う）
- 作業前に必ず最新版を取得する
- こまめにアップロードして変更を早めに共有する

## 1. 初期設定（最初に1回だけ）

### ① GitHub アカウントを作る

1. [github.com](https://github.com) にアクセス
2. 「Sign up」からアカウントを作成
3. **ユーザー名をチームのオーナーに伝えて、リポジトリに招待してもらう**

### ② GitHub Desktop をインストールする

1. [desktop.github.com](https://desktop.github.com) からダウンロード・インストール
2. 起動したら「Sign in to GitHub.com」をクリックしてログイン
3. 名前とメールアドレスを設定（コミット履歴に記録されます）

> **Windows / Mac の人はこのアプリを使えば、コマンドラインを使わずに操作できます。**

## 2. リポジトリをダウンロードする

### GitHub Desktop の場合

1. GitHub Desktop を開く
2. メニュー →「File」→「Clone Repository...」
3. 「URL」タブを選択して、以下を入力：

4. 保存先フォルダを選んで「Clone」をクリック

### Web ブラウザからの場合

1. [リポジトリのページ](https://github.com/ReBot-dev/3s_robodesign_groupwork) を開く
2. 緑色の「Code」ボタン →「Download ZIP」

> ⚠️ ZIP ダウンロードでは git の履歴管理ができません。共同編集するなら GitHub Desktop でクローンしてください。

## 3. 基本の作業フロー

毎回の作業は、この流れで行います。

```
① 最新の状態を取得する（Fetch / Pull）
    ↓
② ファイルを編集・追加する
    ↓
③ 変更を記録する（Commit）
    ↓
④ GitHub にアップロードする（Push）
```

### ① 最新の状態を取得する

作業を始める前に **必ず** やってください。
他の人の変更を取り込まないと、後で衝突が起きます。

**GitHub Desktop：** 画面上部の「Fetch origin」をクリック → 変更があれば「Pull origin」をクリック

### ② ファイルを編集・追加する

普段どおり Fusion 360 等でファイルを編集します。
新しいファイルをリポジトリのフォルダに保存すれば、自動的に検出されます。

### ③ 変更を記録する（コミット）

**GitHub Desktop：**

1. 左側に変更されたファイルの一覧が表示される
2. コミットに含めるファイルにチェックを入れる
3. 左下の「Summary」に変更内容を書く（例：「フライホイールの形状を修正」）
4. 「Commit to main」をクリック

> **コミットメッセージの書き方：** 何をしたかを簡潔に書いてください。
> 例：`実験台の高さを変更`、`ベベルギアを追加`、`不要なファイルを削除`

### ④ GitHub にアップロードする（プッシュ）

**GitHub Desktop：** 画面上部の「Push origin」をクリック

これでチームメンバー全員がこの変更を取得できるようになります。

## 4. ブランチを使った作業

ブランチを使うと、`main`（本流）に影響を与えずに作業できます。
大きな変更をするとき、まだ完成していない作業を保存したいときに使います。

```
main ──●──●──●──────────●── （常に動く最新版）
              \        /
feature/gear   ●──●──●     （作業用ブランチ）
```

### ブランチの作り方（GitHub Desktop）

1. 画面上部の「Current Branch」をクリック
2. 「New Branch」をクリック
3. ブランチ名を入力（例：`feature/gear-redesign`）
4. 「Create Branch」をクリック

これで新しいブランチに切り替わります。あとは普段どおり編集 → コミット → プッシュするだけです。

### main に戻る（GitHub Desktop）

1. 画面上部の「Current Branch」をクリック
2. 「main」を選択

## 5. Pull Request（PR）を出す

ブランチでの作業が完了したら、**Pull Request** を出して `main` にマージ（統合）します。
PR を出すと、チームメンバーに変更内容を確認してもらえます。

### GitHub Desktop から出す方法

1. ブランチで作業をコミット＆プッシュした後
2. 画面上部に「Create Pull Request」ボタンが表示される
3. クリックすると GitHub のウェブページが開く
4. タイトルと説明を書いて「Create pull request」をクリック

### GitHub のウェブサイトから出す方法

1. [リポジトリのページ](https://github.com/ReBot-dev/3s_robodesign_groupwork) を開く
2. 「Compare & pull request」ボタンをクリック（ブランチを push した後に表示される）
3. タイトルと説明を書く（何を変更したか）
4. 「Create pull request」をクリック
5. チームメンバーに確認してもらう
6. 問題なければ「Merge pull request」→「Confirm merge」でマージ

## 6. よくあるトラブルと対処法

### 「Push」できない

他の人が先にプッシュしていて、自分の手元が古い状態です。

**対処：** 「Fetch origin」→「Pull origin」で最新版を取得してから、もう一度プッシュ。

### コンフリクト（衝突）が起きた

同じファイルを複数人が同時に編集すると起きます。

> ⚠️ `.f3d` ファイルはバイナリなので **自動マージできません。**
> どちらの変更を残すか、チームで相談して決めてください。

**防ぐコツ：**
- **同じファイルを同時に編集しない**（これが一番大事！）
- 作業前に必ず「Fetch → Pull」する
- こまめにコミット＆プッシュして変更を早く共有する

### 間違えてコミットしてしまった

GitHub Desktop のメニュー →「Repository」→「Undo Last Commit」で直前のコミットを取り消せます。

> ⚠️ すでにプッシュした後のコミットは取り消さないでください。他の人の作業と衝突します。
